О политике

Используя Сайт, пользователь подтверждает, что ознакомился с настоящей Политикой конфиденциальности.

Данные

1. Какие данные могут собираться

В зависимости от используемых функций Сайта могут обрабатываться следующие данные:

  • IP-адрес;
  • тип и версия браузера;
  • операционная система и тип устройства;
  • дата и время посещения;
  • посещённые страницы;
  • технические журналы и данные об ошибках;
  • cookie-файлы и аналогичные технические идентификаторы;
  • данные, добровольно предоставленные пользователем через формы на Сайте.

Если пользователь выполняет вход через сторонний сервис, например TikTok, Twitch, Discord, Telegram или другой сервис, Сайт может получить только те данные, доступ к которым пользователь разрешил во время авторизации.

В зависимости от стороннего сервиса это может включать идентификатор аккаунта, имя пользователя, отображаемое имя, изображение профиля и другую информацию, явно разрешённую пользователем при авторизации.

Сайт не получает пароль пользователя от стороннего сервиса.
Использование

2. Для чего используются данные

Полученная информация может использоваться для:

  • работы функций Сайта;
  • авторизации и идентификации пользователя;
  • отображения информации аккаунта;
  • предоставления пользовательских функций;
  • обеспечения безопасности;
  • предотвращения злоупотреблений и несанкционированного доступа;
  • диагностики ошибок;
  • улучшения работы и производительности Сайта;
  • ведения технической статистики.

Персональные данные не используются для целей, не связанных с работой Сайта, без соответствующего основания или согласия пользователя.

OAuth

3. Авторизация через сторонние сервисы

Некоторые функции Сайта могут использовать OAuth или другие официальные механизмы авторизации сторонних платформ.

При использовании такой авторизации пользователь перенаправляется на сайт соответствующего сервиса и самостоятельно предоставляет разрешение на доступ к определённым данным.

Обработка информации сторонними платформами регулируется их собственными условиями использования и политиками конфиденциальности.

Сайт не контролирует способы обработки данных сторонними сервисами.

Авторизация

4. Токены доступа

Если для работы функций Сайта используются OAuth access token, refresh token или аналогичные данные авторизации, они используются исключительно для выполнения разрешённых пользователем действий и взаимодействия с соответствующим API.

  • не передаются посторонним лицам без необходимости;
  • не публикуются в открытом доступе;
  • используются только в рамках предоставленных пользователем разрешений;
  • могут быть удалены после отключения интеграции или удаления связанных данных.

Пользователь также может отозвать доступ через настройки соответствующего стороннего сервиса.

Cookies

5. Cookie-файлы

Сайт может использовать cookie-файлы и локальное хранилище браузера для:

  • сохранения пользовательской сессии;
  • авторизации;
  • сохранения настроек;
  • обеспечения безопасности;
  • корректной работы интерфейса;
  • технической аналитики.

Пользователь может ограничить или удалить cookie через настройки своего браузера. При этом некоторые функции Сайта могут перестать работать корректно.

Третьи лица

6. Передача данных третьим лицам

Персональные данные пользователей не продаются третьим лицам.

Информация может передаваться третьим сторонам только в случаях, когда это необходимо:

  • для работы используемого стороннего API или сервиса;
  • для размещения и технического обслуживания Сайта;
  • для обеспечения безопасности;
  • для исполнения требований законодательства или законного запроса уполномоченных органов.

При использовании сторонних сервисов передаётся только информация, необходимая для выполнения соответствующей функции.

Хранение

7. Хранение данных

Информация хранится только в течение срока, необходимого для работы соответствующих функций Сайта, обеспечения безопасности или выполнения применимых требований законодательства.

Технические журналы могут временно сохраняться для выявления ошибок и предотвращения злоупотреблений.

Если данные пользователя больше не требуются, они могут быть удалены или обезличены.

Защита

8. Безопасность

Для защиты данных применяются разумные организационные и технические меры.

При этом ни один способ хранения или передачи информации через Интернет не может гарантировать абсолютную безопасность.

Пользователь также несёт ответственность за безопасность своего устройства и аккаунтов сторонних сервисов.

Удаление

9. Удаление пользовательских данных

Пользователь может запросить удаление персональных данных, связанных с использованием Сайта.

  • имя пользователя или идентификатор аккаунта;
  • сервис, через который выполнялась авторизация;
  • описание данных, которые пользователь хочет удалить.

После подтверждения запроса связанные данные будут удалены в разумный срок, кроме случаев, когда их дальнейшее хранение необходимо в соответствии с законодательством, требованиями безопасности или для разрешения споров.

Пользователь также может самостоятельно отозвать разрешения Сайта в настройках соответствующей сторонней платформы.

Администрация Сайта не несёт ответственности за содержание и правила обработки данных на таких ресурсах.
